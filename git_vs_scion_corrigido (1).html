O que estamos mostrando: um clone completo e convencional do Git. O Git também oferece recursos como --filter e sparse-checkout que podem reduzir o download ou a quantidade de arquivos presentes localmente. Portanto, esta tela não representa todos os modos de usar Git.

E se você precisasse de apenas alguns arquivos?

Selecione arquivos no explorador e veja que o clone completo continua recebendo todos os 1.000 arquivos.
