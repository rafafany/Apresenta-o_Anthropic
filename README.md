# Trabalho — Redesigning Source Control

## Sobre o trabalho

Este repositório apresenta os materiais desenvolvidos para o trabalho acadêmico baseado no artigo **Redesigning Source Control**, publicado pela Anthropic.

O trabalho aborda os desafios enfrentados pela Anthropic diante do crescimento da utilização de agentes de Inteligência Artificial no desenvolvimento de software.

O artigo apresenta como o aumento significativo da produção de código passou a exigir mudanças nas ferramentas tradicionais de controle de versão, levando a empresa a desenvolver uma nova solução chamada **Scion**.

São discutidos aspectos relacionados à produtividade no desenvolvimento de software, escalabilidade, controle de versão, limitações do Git e às novas necessidades de infraestrutura geradas pela utilização de agentes de IA.
